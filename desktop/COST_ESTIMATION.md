# 利用実績の推定コスト

利用実績のコストは、保存済みのトークン数をAPIの標準単価へ換算した参考値です。サブスクリプションの支払い額、残高、請求額を表すものではありません。通貨はUSDです。表示のための追加のAI実行や料金取得通信は行いません。

## 料金表と計算

組み込みの [料金表](ChatAgentBridge.Core/Pricing/model-prices.json) は2026年10月20日に確認した値です。各単価は100万トークンあたりのUSDで、通常入力・キャッシュ読み取り・キャッシュ書き込み・出力を分けています。単価の変更はこのファイルと計算テストを更新してアプリを再ビルドします。過去の記録も、このアプリに組み込まれた料金表で再計算します。

基本式は次のとおりです。

```
(通常入力 × 入力単価
 + キャッシュ読み取り × 読み取り単価
 + キャッシュ書き込み × 書き込み単価
 + 出力 × 出力単価) / 1,000,000
```

入力トークン数にキャッシュ分が含まれる場合は、判明しているキャッシュ分を通常入力から差し引き、重複計上を防ぎます。キャッシュ内訳が不明でも入力全体が判明していれば、内訳によって変わる算定幅を表示します。キャッシュ分を別に報告する形式で必須の内訳が欠けている場合は、未算出にします。

キャッシュ保持期間や長いコンテキストへの料金条件を履歴だけでは特定できない場合も、確認できた標準単価の範囲で幅を表示します。グラフの棒の高さにはその上側の値を使います。範囲は、あらゆる請求条件を含む保証額ではありません。Fastモード、リージョン加算、ツールの追加料金、税、割引、為替換算は対象外です。

## 未算出と集計範囲

- 不明なモデル、未対応の単価、必要なトークン数の不足、不正な値は、0ドルとして扱いません。
- 実際に報告されたモデルを使います。設定で指定したモデルを、不明な実行モデルの代用にはしません。
- 算出できた実行と未算出の実行が混在する場合、表示額は算出できた分の小計です。算出件数を併記します。
- 選択した利用集計の範囲に合う実行だけを対象にし、会話の累積値と1実行分を足し合わせません。同じ実行IDも重複計上しません。
- 保存されたトークン数だけが対象です。CLIがサブエージェント等の利用量を含めていなければ、その分はこの推定にも含まれません。
- 表示の探索によって保存済みの実行履歴や接続設定を書き換えることはありません。

Claudeの `total_cost_usd` は、再開したセッションでは以前のコストを含む場合があります。この実装では、その値を各実行のコストとして加算せず、既存のトークン記録から計算します。
