These CAB outline icons reuse the provider motifs in AgentSettings/SettingsScopeIcons.xaml.
They are not official service logo assets. SVG is the editable source.
The 96px transparent PNG is used by WinUI BitmapIcon with ShowAsMonochrome=True,
so Windows controls foreground color for light, dark and contrast themes.
PNG generation: CairoSVG, 96 x 96 pixels; retain source proportions and alpha.
CAB original artwork is covered by the repository MIT license.
