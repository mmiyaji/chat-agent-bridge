Chat Agent Bridge ポータブル版

これは Windows x64 / ARM64 向けの展開型プレビュー版です。Windows 11 を推奨し、Windows 10 の対応下限は 1809（ビルド 17763）です。アプリ本体は .NET と Windows App SDK を含むため、別途インストールする必要はありません。インストーラー、MSIX登録、証明書のインストール、Windows の開発者モードは不要です。

使い方
1. ZIP の中にある ChatAgentBridge.Portable フォルダー全体を、書き込み可能な場所へ展開します。
2. フォルダー内の ChatAgentBridge.Desktop.exe を起動します。
3. 初回起動時、アプリのデータは実行ファイルと同じフォルダーに作成される Data フォルダーへ保存されます。配布 ZIP には利用者のデータや設定は含まれません。

認証情報とデータ
Codex、Claude Code、Gemini CLI、GitHub Copilot CLI など利用する CLI は別途インストールし、CLI 自身でログインしてください。アプリに保存した Slack / Mattermost 接続トークンは Windows DPAPI で保護され、同じ Windows ユーザーと PC で利用できます。他の PC へ移す場合は、元の PC で接続トークンを空にして保存してからコピーし、移行先でトークンを再入力してください。暗号化した設定をそのまま移すと安全のため読み込みを停止します。その場合は、終了後に Data/settings.json を退避して初期設定をやり直してください。CLI のログインと作業フォルダーも移行先で確認してください。Data フォルダーを含むアプリフォルダーは、利用者のデータを含むため安全に保管してください。

自動起動と削除
アプリフォルダーを移動する前に、アプリの「全般」で Windows サインイン時の自動起動をオフにします。移動後に必要であれば再度有効にしてください。削除する場合も、先に自動起動をオフにしてからアプリを終了し、アプリフォルダーを削除します。ユーザー単位の Windows 通知登録が残る場合があります。アプリは PC 全体へのインストールを行いません。

通知用IDの任意設定
通常の通知は追加設定なしで利用します。通知互換性のための署名済み Identity フォルダーが同梱された版では、Windows 10 バージョン 2004 以降の「全般」→「Windows通知」から、ユーザー単位のパッケージ登録を選べます。Windows が信頼する発行元の署名が必要です。証明書の信頼は自動では変更しません。登録した場合は、フォルダーの移動・削除前にこの画面で登録を解除してください。設定と履歴は保持されます。登録後の更新にも対応する Identity フォルダーが必要で、これを除去する更新は安全のため適用しません。

更新
ポータブル版の更新を確認するときは、「情報」の「更新を確認」を手動で実行します。提示されたバージョンを確認してダウンロードし、明示的な再起動操作を選ぶと更新が適用されます。更新プログラムは portable-files.json に記載されたファイルだけを置き換え、Data フォルダーや一覧にないファイルは保持します。更新前に Data のバックアップを別に保存してください。更新プログラムは自己完結型の Windows 実行ファイルで、PowerShell や管理者権限は不要です。以前のポータブル版には更新プログラムが含まれないため、アプリ内更新を使う前に一度、新しい ZIP をダウンロードして展開してください。

ファイル
- SHA256SUMS.txt は ZIP 内の各ペイロードファイルの SHA-256 ハッシュです。
- portable-release.json はリリースバージョンと x64 / ARM64 のアーキテクチャを示します。
- portable-files.json は更新プログラムが管理するファイルの一覧です。
- 配布元が ZIP 用に提供する .sha256 ファイルで、ダウンロードした ZIP のハッシュを確認できます。

プレビュー版のため、重要なデータは別途バックアップしてください。
