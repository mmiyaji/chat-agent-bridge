# README screenshots

Captured on Windows on 2026-10-24 from the native desktop development build,
including the Chat / History and usage navigation labels.

- `*-ja.png`: Japanese, dark appearance.
- `*-en.png`: English, light appearance.
- Each image is an unedited 1226 × 953 native window capture.
- The app used separate demo data directories, not the user's normal profile.
- Chat was disconnected, tokens were absent, and no AI requests were made.
- History screenshots contain 70 generated example executions across 28 days.
  Their counts, tokens and model names are sample data, not performance results.
- Setup/agent screenshots intentionally show unchecked CLI and disconnected chat
  rather than presenting a simulated connection as a live service.

When refreshing, use an isolated profile with no credentials, disable update and
price-table network checks, capture the same four pages in both languages, and
review every image for clipping, error banners and sensitive information before
replacing the files. Update the screenshot date in both root READMEs.
