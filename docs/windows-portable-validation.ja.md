## 初回ポータブル配布（2026-10-19）

配布タグは `v0.1.0-preview.2`、アプリのバージョンは `0.1.0.1`。既存のMSIXプレビューを残し、x64・ARM64の自己完結型ポータブルZIPを追加する。`CABPortable=true` の場合だけ非パッケージ形式を選び、通常のMSIXビルドの設定と出力先を維持する。

## 配布形式と保存先

ZIP内の `ChatAgentBridge.Portable` フォルダー全体を、書き込み可能な場所へ展開して `ChatAgentBridge.Desktop.exe` を起動する。MSIX登録、証明書の信頼登録、管理者権限、開発者モードは不要。.NETとWindows App SDKを同梱する。利用するエージェントCLIとそのログインは別途必要。

初期設定・履歴などはEXE隣の `Data` に保存する。明示的な `--data-dir`、環境変数 `CAB_WINUI_DATA_DIR` があれば、従来どおり優先する。アプリに保存するSlack / MattermostトークンのDPAPI保護は維持する。別PCへのデータ移行では元のPCでトークンを空にして保存し、移行先で再入力する。暗号化した設定をそのまま移して読み込めない場合は、終了後に `Data/settings.json` を退避して再設定する。

自動起動は現在のWindowsユーザーのRunキーだけを使用し、別の配置の登録やWindows側の無効化を上書きしない。アプリフォルダーを移動・削除する前に自動起動をオフにする。

## 確認結果

- Core 242件、Transports 93件、合計335件のテストが成功。翻訳キー・書式検査、変更したPowerShellスクリプトの構文検査も成功。
- 通常のMSIX Releaseビルドは警告0・エラー0。通常利用中のアプリと接続設定を変更せず、専用データで試験した。
- x64 ZIPを展開した実物を、別の作業ディレクトリから直接起動。`GetPackageFullName` が15700（パッケージIDなし）を返すことを確認。
- ポータブル起動の5項目が成功。初回言語の即時変更、EXE隣への言語・テーマ保存、空白と日本語を含むパスでの自動起動オン・オフと連打抑止、言語変更による実際の再起動と設定保持、情報ページのバージョン表示を確認。
- 会話UIは日本語ダーク・英語ライトで各12項目を検証。42件の保存済み会話、検索・絞り込み・選択保持、狭い画面の一覧と詳細、新規開始の確認と対象限定、利用者別分離、承認・結果共有・停止、Windows通知の登録を含む。
- 会話試験はループバックのMattermostプロトコル用フィクスチャとモデルを呼ばないCLIを使用。実サービスや実際のAIへの依頼は今回行っていない。
- 英語試験の初回は、共有確認のキャンセル直後に非同期コマンドの終了を待たずボタンを再操作して失敗した。試験側で共有ボタンの再有効化を待つよう修正した。
- x64は538ファイル、ARM64は534ファイルを検査。PEのアーキテクチャ、自己完結型runtimeconfig、必須ランタイム、全ペイロードのSHA-256を確認。設定・履歴・トークン・秘密鍵・証明書・インストーラー・テストCLIを含まないことを検査し、`Data` を追加した負例も拒否した。

Windows App SDK 2.5.1の自己完結型出力では通知登録に必要な `Microsoft.WindowsAppRuntime.Insights.Resource.dll` が欠ける問題があるため、復元済みの同バージョン公式NuGet内Runtime MSIXから該当アーキテクチャのDLLをビルド時に抽出して同梱する。x64で通知登録と承認待ち通知の表示が成功することを確認した。[上流の問題報告](https://github.com/microsoft/WindowsAppSDK/issues/6774)

## 検証範囲

ARM64は発行と内容検査までで、実機起動は未検証。別の物理PCおよび開発ツールやランタイムのないクリーンWindowsでの起動も未検証。今回確認したのは、このPCでのx64非パッケージ起動と同梱ランタイムの構成であり、別PCでの実測ではない。

手元のUI試験証跡は `desktop/artifacts/portable-ui-d0e19d7fe9294f6c8564bfe82b91e4aa`、日本語 `desktop/artifacts/conversation-ui-5f60608a748f47e588b97bebaf9fcfda`、英語 `desktop/artifacts/conversation-ui-95a7a01a720949c2833c30a3ac1f642b` に保存。証跡やテストデータは配布ZIP・Gitの対象外。

再現用コマンドは `desktop/Create-PortableArchive.ps1 -Architecture x64`（または `ARM64`）。`-ValidateOnly -ArchivePath <ZIP>` で配布内容を再検査できる。`desktop/PortableUiE2E.ps1` と `desktop/ConversationUiE2E.ps1 -Portable -Language ja` / `en` は、`desktop/artifacts` 配下の展開済みペイロードを対象に実行する。
