# ページ左右余白の検証

2026-11-11、`fix/history-ui-clarity` で実施。

## 変更

- ページ外周の左右余白を共通コンテナーで管理。コンテナー幅が720 DIP以下では16 DIP、それより広い場合は24 DIP。
- エージェント設定・チャット接続設定の本文では、横並びのサブナビゲーションとの間だけ16 DIPを残す。上部ナビゲーション時には追加の横余白を外す。
- 「情報」ページ本文の右側だけにあった追加16 DIPを削除。カードと表の内部余白は既存の配置を維持。

## 結果

- Release・x64・自己完結型ポータブルビルド成功。既存のCsWinRT1032警告あり。
- `ChatHistoryResponsiveUiSmoke.ps1` の英語・ライト／ダークのチャット／履歴シナリオが成功。日本語シナリオの前に中断しており、全言語の完走結果ではない。
- 隔離プロファイルによる座標検査で、全7ページを1280 → 500 → 1280 DIPに切り替え、21ケースすべて成功。
- 500 DIPでは全ページの見出し左余白・表示コンテンツ右余白が16 DIP。1280 DIPでは右24 DIP、見出し左25 DIP（NavigationView境界線1 DIPを含む）を確認。許容誤差は1 DIP。
- 狭幅ではエージェント設定・チャット接続設定のパンくずも見出しと同じ左端になることを検査。通常幅に戻しても余白を復元。
- 設定2ページの通常幅／狭幅スクリーンショットを確認。

一時スクリプトは `.artifacts/check-page-insets.ps1`。座標と画像の出力は `desktop/artifacts/page-insets-ca89498e7922414b96b3be8d83bf5910/`（コミット対象外）。UI Automationが非表示のGridを公開せず、一部の領域で幅変更前の境界を返すため、実ウィンドウのクライアント領域で表示要素の座標をクリップして比較した。

外観のみの変更のため、CLI実行・実チャット接続・Core/Transportsの全件テストは再実施していない。
