# 全般タブへの設定集約と検証（2026-10-20）

## 配置

「概要」を「全般」に変更し、独立した「外観」メニューを統合しました。表示順は次のとおりです。

1. 現在の状態と、設定先へのステータスリンク
2. Windowsログイン時の自動起動、アプリ起動時の自動接続先
3. システム トレイでの常駐、格納、完全終了
4. 言語とカラーテーマ
5. セットアップの詳細と構成図（初期状態は展開）

エージェント設定はCLIと実行設定、接続設定はチャットの認証・承認・添付・許可範囲に集中させました。既存の設定ファイルはそのまま利用でき、初期設定のやり直しは不要です。

自動接続先には専用の保存ボタンを追加しました。保存済み設定を読み直し、自動接続先だけを更新します。ほかのタブの未保存の編集は保存・破棄しません。起動、トレイ、言語、テーマは従来どおり個別に保存します。言語変更後の再起動確認と、未保存の編集がある場合の再起動ブロックを維持しています。
