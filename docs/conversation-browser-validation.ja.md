# 会話一覧の改善（未公開）

同じサービス・ユーザーの会話を区別しやすくするため、「履歴と会話」の一覧を変更した。

- 見出しは任意の会話名。未設定なら作業フォルダー名を表示する。
- サービスと利用者、作業先とAI・モデル、最後の実行状態と実行回数、更新日時を一覧へまとめる。内部IDは詳細の折りたたみで確認する。
- 会話名も検索でき、サービス・作業フォルダーで絞り込める。最近更新した順・会話名順・実行回数順を選べる。
- 詳細の鉛筆ボタンから80文字までの名前を設定する。空欄でフォルダー名へ戻せる。更新・再起動・会話継続でも名前を保持し、別ユーザーの会話を変更しない。
- 狭い画面では補助フィルターを折りたたみ、詳細表示中は検索欄を隠す。一覧へ戻る操作と、モデル・承認設定・新規開始の操作を確保する。

会話名はこのアプリ内の表示用であり、チャットのスレッド名を変更しない。本文・結果の保存や、名前を付けるためのAI呼び出しは行わない。表示名を実行設定や認可の判定に使用しない。

実行回数と最終状態は、サービス・チャンネル・スレッド・利用者・CLIセッションIDが一致する記録から集計する。同じ識別情報に複数サーバーが対応する場合は、帰属を決められないため集計を表示しない。過去の別CLIセッションや別ユーザーの記録は加算しない。

名前の保存はファイル単位の排他処理で行い、長いAI実行の終了を待たない。実行終了時に古い会話データが保存されても、直近の表示名を維持する。
