# Chat Agent Bridge 1.1.2-preview.2

## 日本語

- 監査ログの内容を増やしました。チャットの依頼で再承認が必要になった理由、実行がキャンセルされた理由（アプリやチャットでの停止、接続の切断、設定変更など）、承認の方法、チャット接続の開始・再接続・切断、アプリの起動・終了、セキュリティに関わる設定の変更を記録します。
- 実行中にチャットの接続が切り替わっても、完了・キャンセルなどの最終状態をチャットの進捗メッセージに反映するようにしました。更新できない場合はスレッドに返信します。
- 利用状況のカレンダーをダークテーマで見やすくし、利用の多い日ほど明るく表示します。
- CLI の確認画面の余白とバージョン表示を整理しました。推論レベルを指定していないときは「CLIの既定値」を選択状態にします。エージェントのアイコンを 20px でくっきり表示します。
- ポータブル更新が失敗したときの表示を分かりやすくし、登録済みの CLI 実行ファイルが変わったときに再確認を促します。

GitHub Releases で x64・ARM64 のポータブル ZIP を配布するプレビュー版です。Microsoft Store 版は含みません。

## English

- The audit log records more: why a chat request needed approval again, why a run was cancelled (stopped in the app or chat, connection lost, settings changed, and so on), how it was approved, chat connection start, reconnect and disconnect, app start and stop, and changes to security-relevant settings.
- When the chat connection changes during a run, the final state (completed, cancelled, and so on) still reaches the chat progress message. If it cannot be edited, the app replies in the thread.
- The activity calendar is easier to read in dark mode; busier days are brighter.
- Tidied the spacing and version details on the CLI check screen. When no reasoning level is set, "CLI default" is selected. Agent icons render sharply at 20px.
- Portable update failures are explained more clearly, and a changed CLI executable prompts you to check it again.

This preview provides portable ZIPs for x64 and ARM64 on GitHub Releases. The Microsoft Store version is not included.
