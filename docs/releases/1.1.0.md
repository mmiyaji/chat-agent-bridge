# Chat Agent Bridge 1.1.0

## 日本語

- Slack・Mattermost・Discordの接続設定と初回設定ウィザードで、Botが参照できるチャンネルを名前で検索して選べるようになりました。Mattermostは送信先チャンネル、Slack・Discordは許可チャンネルを選択します。
- 初回設定ウィザードは、Botとの専用DMを使う推奨の流れに整理しました。DM受付は新規設定で有効になり、共有チャンネルやサーバーの制限は必要に応じてチャット設定から指定できます。
- 許可ユーザー一覧に表示名を併記し、ユーザーを識別しやすくしました。
- チャット接続設定、初回設定、CLI確認、履歴表示などを改善し、設定変更の検知と引き継ぎを見直しました。
- 初回設定の同意状態を保存し、ポリシー版が変わった場合に再同意を求められるようにしました。アップデート後にはホーム画面で変更案内を表示します。
- アプリの起動時接続、作業中のスリープ抑止、保存先を開く操作などの設定を改善しました。

Microsoft Store版は、ストア審査・公開後にMicrosoft Storeから配信します。ポータブル版はGitHub Releasesから配信します。

## English

- Chat settings and the first-run wizard can search for channels visible to the bot and select them by name. Mattermost uses the selection as the destination channel; Slack and Discord use it as an allowed-channel list.
- First-run setup now follows the recommended flow of using a dedicated DM with the bot. DM access is enabled for new configurations, while shared-channel and server restrictions can be added later in chat settings.
- Allowed-user lists now include display names to make users easier to identify.
- Chat connection settings, onboarding, CLI verification, and history views have been improved, along with settings-change detection and persistence.
- Onboarding consent is persisted and can be requested again when the policy version changes. The home page also shows a brief update notice after an upgrade.
- Startup connection, sleep prevention during work, and opening the settings folder have been improved.

The Microsoft Store edition will be available from Microsoft Store after Store review and publication. The portable edition is distributed through GitHub Releases.
