# Chat Agent Bridge 1.1.0-preview.1

## 日本語

- 履歴を「会話」「実行記録」「利用状況」に整理しました。実行の詳細から関連する操作を確認できます。拒否など実行に至らなかった操作は「すべての操作」で確認できます。
- チャットの共通設定で許可ユーザーを管理できます。Mattermost と Slack はユーザー検索、Discord は ID 入力に対応します。ユーザーごとのアクセス許可履歴も開けます。
- 許可ユーザーに対する承認の初期設定と、未許可ユーザーからの依頼を PC で確認する流れを見直しました。実行結果の初期設定は自動共有です。
- 長い出力でもエラーの診断情報を保持し、機密情報を除いた診断コードを記録します。中断した実行履歴も起動時に復旧します。
- 表のアイコン、絞り込み、詳細ペイン、狭いウィンドウでの診断表示を改善しました。

GitHub Releases で x64・ARM64 のポータブル ZIP を配布します。トリミングは引き続きローカルの試験ビルド用です。

## English

- History is organized into Conversations, Run records, and Usage. Run details show related actions. All actions also includes requests that never ran.
- Manage allowed users from the common chat settings. Search for Mattermost and Slack users, or enter a Discord user ID. You can also open the History page’s Access tab filtered to an individual user.
- Updated approval defaults for allowed users and the desktop review flow for requests from users who are not yet allowed. Results are shared automatically by default.
- Long output retains error diagnostics, and logs record diagnostic codes without sensitive details. Interrupted runs are reconciled at startup.
- Improved table icons, filter placement, the detail pane, and diagnostics in narrow windows.

GitHub Releases provides portable ZIPs for x64 and ARM64. Trimming remains an option for local experimental builds.
