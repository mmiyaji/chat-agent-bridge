# Chat Agent Bridge 1.1.0-preview.3

## 日本語

- トリミングを有効にした自己完結型ポータブル版です。x64 と ARM64 の ZIP を配布します。
- ZIP の容量は x64 が 93.2 MB、ARM64 が 89.8 MB です。
- 1.1.0-preview.2 から更新できます。設定と履歴が引き継がれることを確認しました。
- 履歴と診断の更新ボタンに、待機中の更新アイコンと実行中のスピナーを表示します。狭いウィンドウで履歴表を横スクロールしたときの列位置も確認しました。
- トリミング解析の JSON 反射に関する警告は残っています。利用する CLI・チャットサービスの接続と送受信を確認してください。

Microsoft Store 版は含みません。通常版の設定・認証情報と分けて試してください。ARM64 ZIP はクロスビルドと形式を検証していますが、ARM64 実機での起動試験は行っていません。

## English

- Self-contained portable builds with trimming enabled. ZIPs are available for x64 and ARM64.
- ZIP sizes are 93.2 MB for x64 and 89.8 MB for ARM64.
- Portable updates from 1.1.0-preview.2 preserve settings and history.
- History and diagnostics refresh buttons show a refresh icon while idle and a spinner while refreshing. Narrow-window history tables were checked while horizontally scrolling.
- Trim analysis warnings remain for reflection-based JSON serialization. Verify the CLI and chat services you use, including connecting and sending and receiving messages.

No Microsoft Store package is included. Test Preview builds with data kept separate from your regular installation. The ARM64 archive was cross-built and validated, but was not run on ARM64 hardware.
