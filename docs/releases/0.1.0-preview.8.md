## 主な変更

- 利用実績を永続集計し、詳細履歴が500件を超えても日別・モデル別の集計を保持します。すでに削除された古い詳細履歴は復元されません。
- 情報画面に診断情報の確認と通知テストを追加しました。診断レポートは保存前にプレビューでき、許可された情報だけをローカルに保存します。通知テストはAI実行や承認を行いません。
- エージェントと接続先の非機密設定をバックアップ・復元できます。復元後は認証のやり直しと作業フォルダーの信頼確認が必要です。履歴、会話メモ、利用実績、通知診断データは全般画面から削除できます。
- ダウンロード済みの更新は「あとで」を選んで終了しても保持され、次回起動時に再検証して案内します。
- 設定画面の項目表示と、診断レポートの複数行プレビューを修正しました。実行履歴・監査履歴の空表示と更新再起動時の案内も改善し、更新バッジのアイコンと同梱ライセンスの表示を整えました。

## Main changes

- Usage statistics are persisted, so daily and model totals remain available beyond the 500-item detailed-history limit. Older detail that was already evicted cannot be recovered.
- The About page adds diagnostics and a notification test. You can preview a support report before saving; only allowlisted information is saved locally. The notification test does not run AI or request approval.
- Back up and restore non-secret agent and connection settings. Restoring requires authentication again and explicit workspace trust. Clear history, conversation notes, usage statistics, and notification diagnostics from General settings.
- A downloaded update is retained when you choose “Later” and exit, then revalidated and offered again at next launch.
- Fixed settings item styling and multiline support-report previews. Improved empty execution/audit history states and the update restart prompt, and refreshed the update badge icon and bundled license viewer.

## 前バージョンからの更新 / Updating from the previous version

`0.1.0-preview.7` の「情報」→「更新を確認」から更新できます。プレビュー版を含める設定を有効にしてください。既存の設定・データは引き継がれ、管理者権限や初期設定のやり直しは不要です。設定バックアップを復元する場合は、認証と作業フォルダーの信頼を改めて確認してください。

Update from **About → Check for updates** in preview.7 with preview releases enabled. Existing settings and data are retained; administrator access and initial setup are not required again. Restoring a settings backup requires authentication and workspace trust to be confirmed again.

x64版・ARM64版のZIPとSHA-256チェックサムを配布します。

Portable ZIPs and SHA-256 checksums are provided for x64 and ARM64.

## 検証と制約 / Validation and limitations

- ローカルでCoreテスト879件、Pythonテスト19件、日英・ライト／ダークのUI検証56項目が成功しました。
- Windows通知の実際の表示はPC側の設定・環境に依存します。通知テストの送信成功はバナー表示の保証ではありません。
- ARM64はクロスビルドと配布形式の検証です。ARM64実機と、Google認証エラーで保留中のGemini実サービス検証を代替しません。

- Local validation passed 879 Core tests, 19 Python tests, and 56 UI checks across Japanese/English and light/dark themes.
- Windows notification delivery depends on PC settings and environment. A successful test enqueue does not guarantee a visible banner.
- ARM64 is cross-built and package-validated, without an ARM64-device run. Gemini service verification remains deferred because of Google authentication errors.
