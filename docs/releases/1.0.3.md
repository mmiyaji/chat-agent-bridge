# Chat Agent Bridge 1.0.3

## 日本語

### 主な変更

- **ポータブル版の更新を一時停止・再開できるようになりました。** アプリを閉じて再起動した後もダウンロードを再開できます。画面の一時停止・再開・キャンセル操作を使えます。通信が途切れた場合は最大3回再試行し、データが5分間届かない場合にタイムアウトします。進捗には受信量、速度、残り時間、通信待ち・再試行、検証段階を表示します。
- **CLI操作の応答性と作業フォルダーの保護を改善しました。** CLIの確認、モデル取得、実行準備をバックグラウンドで行い、PCで指定・保存した作業フォルダーを信頼対象へ追加できます。チャットから指定されたフォルダーは自動で信頼しません。
- **Muse CodeをPreviewエージェントとして追加しました。** CLIのセッションIDを使って会話を継続し、確認済みのセッションは実行失敗後も次の依頼で再開できます。
- **Kimi Code CLIの会話再開と承認表示を強化しました。** 再開時の権限モードを確認し、内容を判定できないツール操作には注意を表示します。承認待ちの時間は実行時間制限から除外します。

### 制限・未検証事項

- Muse Codeの実サービス認証・課金を伴う実行は未検証です。モデル一覧取得と実行中依頼への直接追記には対応せず、追加依頼は順番に処理します。
- Kimi Code CLIとQwen Codeの認証済み実サービス応答、チャット経由の会話継続・モデル切り替え・返信は未検証です。確認時にKimiは契約上の利用権不足、QwenはAPIキー制限によるHTTP 403となりました。両CLIは引き続きPreviewです。

## English

### Highlights

- **Pause and resume portable update downloads.** Downloads can resume after closing and reopening the app, with pause, resume, and cancel controls in the UI. Interrupted transfers are retried up to three times and time out after five minutes without incoming data. Progress shows received bytes, transfer speed, estimated time remaining, connection wait and retries, and verification stages.
- **Improve CLI responsiveness and workspace protection.** CLI checks, model retrieval, and execution preparation run in the background. Workspaces selected and saved on the PC can be added to the trusted list; workspace paths supplied by chat are not trusted automatically.
- **Add Muse Code as a Preview agent.** Conversations continue using CLI session IDs, and a session confirmed to belong to the conversation can be resumed on the next request after a failed run.
- **Strengthen Kimi Code CLI resume and approval handling.** The configured permission mode is checked when resuming, and tool operations whose contents cannot be assessed are marked with a caution. Time spent waiting for approval is excluded from the execution timeout.

### Limitations and unverified behavior

- Authenticated Muse Code service use, including any paid execution, was not tested. Model listing and adding input to a running request are unsupported; additional requests are queued.
- Authenticated service responses from Kimi Code CLI and Qwen Code, and chat-based conversation resume, model switching, and replies, remain unverified. During checks, Kimi returned HTTP 403 because the account lacked the required entitlement, while Qwen returned HTTP 403 due to API-key restrictions. Both CLIs remain Preview.
