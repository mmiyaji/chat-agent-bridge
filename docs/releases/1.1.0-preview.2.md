# Chat Agent Bridge 1.1.0-preview.2

## 日本語

- Windows SDK と .NET WinRT 投影をトリミングしたポータブル版を配布します。x64 と ARM64 の自己完結 ZIP を含みます。
- x64 ZIP は Preview.1 の 131.5 MB から 93.2 MB に縮小しました（約29%減）。
- 1.1.0-preview.1 からポータブル更新できます。更新時は設定と履歴を保持します。
- トリミングに伴う注意を確認する Preview です。CLI 接続、チャット接続、Windows App SDK のファイル選択など、利用する操作を確認してください。
- チャット連携の JSON 反射シリアライズに関するトリミング解析警告は残っています。各サービスの接続・送受信を確認してください。

Microsoft Store 版は含みません。Preview は通常版の設定・認証データと分離して試してください。

## English

- This preview ships portable builds with trimming applied to the Windows SDK and .NET WinRT projections. Self-contained x64 and ARM64 ZIPs are available.
- The x64 ZIP is 93.2 MB, down from 131.5 MB in Preview.1 (about 29% smaller).
- Portable updates from 1.1.0-preview.1 preserve settings and history.
- This Preview validates the trimmed build. Check the operations you use, including CLI and chat connections and Windows App SDK file pickers.
- Trim analysis warnings remain for reflection-based JSON serialization in chat transports. Verify each service’s connection and message handling.

No Microsoft Store package is included. Test Preview builds with data kept separate from your regular installation.
