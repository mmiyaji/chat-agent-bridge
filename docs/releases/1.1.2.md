# Chat Agent Bridge 1.1.2

## 日本語

- 同じ会話の以前の実行で生成したファイルをチャットに添付でき、候補の範囲を会話内またはワークスペース全体から選べます。ワークスペース全体の共有には明示的な承認が必要です。添付候補の分離、設定変更後の再確認、受信ファイルの復旧も改善しました。
- 許可ユーザーが未登録でもチャットに接続し、最初の依頼をこの PC で承認できます。チャット設定の変更後の再接続を改善しました。受信箱に依頼がある場合は、内容を確認して手動で再接続します。
- 監査ログに再承認やキャンセルの理由、承認方法、接続状態、セキュリティに関わる設定の変更などを記録します。
- 履歴と利用状況、画面の余白やスクロール、CLI の確認画面を見やすくしました。アクセントカラーも選択できます。
- ポータブル更新の待機処理と失敗時の案内を改善しました。

x64・ARM64 のポータブル ZIP を配布します。Microsoft Store 版は含みません。添付 UI の検証には模擬チャットを使用しており、今回の変更の実チャットサービスでの再検証と ARM64 実機での起動確認は行っていません。

## English

- Attach files generated by earlier runs in the same conversation and choose candidates from that conversation or the whole workspace. Sharing from the whole workspace requires explicit approval. Attachment isolation, rechecking after settings changes, and incoming file recovery have also improved.
- Connect chat before registering an allowed user and approve the first request on this PC. Reconnection after chat settings changes has improved. When requests remain in the inbox, review them and reconnect manually.
- The audit log records reasons for renewed approval and cancellation, approval methods, connection state, and security-relevant settings changes.
- History, activity, screen spacing and scrolling, and CLI checks are easier to read. You can also choose an accent color.
- Improved portable update waiting and failure messages.

Portable ZIPs are available for x64 and ARM64. The Microsoft Store version is not included. Attachment UI checks used a mock chat service; these changes were not re-tested against a live chat service or on ARM64 hardware.
