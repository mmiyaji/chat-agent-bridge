# Chat Agent Bridge 1.1.1

## 日本語

- チャットと履歴の読み込みをバックグラウンドで行い、画面切り替え時の負荷を減らしました。初回は読み込み中と表示し、再読み込み中は表示済みの内容を保持します。
- 狭いウィンドウで設定と履歴の余白を調整し、履歴の件数表示を表の先頭列に揃えました。
- 更新後のお知らせをどのページからでも見える上部に移しました。閉じた後は「情報 → 主な変更点」で確認できます。
- ポータブル更新のローカルエラーに、失敗した段階、判定できた原因、問い合わせ用コードを表示します。
- 許可ユーザーが未登録でもチャットに接続できます。対象範囲内の最初の依頼は、PCで許可してから実行します。
- Mattermostで共有チャンネルを特定のスレッドに限定しても、その制限は個別DMには適用されません。個別DMには、DMの受付設定、許可ユーザー、承認方法が適用されます。
- チャンネル検索のキャンセルと、チャットから承認する際の権限の再確認を修正しました。

## English

- Chat and history load in the background to reduce work during page switches. The first load shows an indicator, and refreshes keep the current content visible.
- Settings and history have more consistent spacing in narrow windows. The history count aligns with the first table column.
- The post-update notice appears at the top of every page. After dismissing it, see **About → What's new**.
- Portable update errors during local processing show the failed stage, the cause when identified, and a support code.
- Chat can connect with an empty allowed-user list. An in-scope first request waits for approval on the PC before it runs.
- Mattermost shared-channel thread restrictions do not apply to personal DMs. Personal DMs follow the DM setting, allowed-user checks, and approval policy.
- Channel search handles cancellation correctly. Approval actions from chat recheck current access.
