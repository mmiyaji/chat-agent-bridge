# Chat Agent Bridge 1.1.2-preview.3

## 日本語

- 同じ会話の以前の実行で生成したファイルを添付できるようにし、会話内のファイルとワークスペース全体のどちらを候補にするか選べます。ワークスペース全体の共有には明示的な承認が必要です。
- 添付候補の分離、設定変更後の再確認、会話削除時の記録削除、受信ファイルの復旧を改善しました。除外されたファイルは名前をチャットに投稿せず、件数で通知します。
- ポータブル更新時に、元のアプリが終了するまで更新ヘルパーが待つようにしました。
- チャット設定を保存して接続が切り替わった場合の再接続、アクセントカラーの選択、画面の余白と表示を改善しました。

GitHub Releases で x64・ARM64 のポータブル ZIP を配布するプレビュー版です。Microsoft Store 版は含みません。今回の添付 UI は模擬チャットを使って検証しています。実チャットサービスでの今回の変更の再検証と ARM64 実機での起動確認は行っていません。

## English

- Attach files generated in earlier runs of the same conversation, and choose whether candidates come from that conversation or the whole workspace. Sharing from the whole workspace requires explicit approval.
- Improved isolation of attachment candidates, rechecking after settings changes, removal of records when a conversation is deleted, and recovery of incoming files. Excluded files are reported by count without posting their names in chat.
- During a portable update, the update helper now waits for the original app to exit.
- Improved reconnection after saving chat settings, accent color selection, and screen spacing and presentation.

This preview provides portable ZIPs for x64 and ARM64 on GitHub Releases. It does not include a Microsoft Store version. Attachment UI checks used a mock chat service; the changes were not re-tested against a live chat service, and the ARM64 build was not tested on ARM64 hardware.
