# Chat Agent Bridge 1.1.2-preview.1

## 日本語

- 許可ユーザーが未登録でもチャットに接続でき、最初の依頼をこのPCで承認できるようになりました。Mattermost の個別DMの受付範囲も案内に明記しました。
- 履歴の表示を整理しました。操作一覧の対象ユーザー列は狭いウィンドウでも読める幅を保ち、会話一覧は並べ替えや絞り込みの後に先頭から表示します。ユーザー名は許可設定と履歴で共通に表示します。
- フライアウトの背景をウィンドウ（Mica）になじむアクリルにし、ページタイトルの上下の余白を詰めました。ページの余白とスクロールの動きも揃えました。
- ポータブル版で通知アイコンがダークテーマでオレンジに見える問題を修正しました。ポータブル更新が失敗したときの表示も分かりやすくしました。

GitHub Releases で x64・ARM64 のポータブル ZIP を配布するプレビュー版です。Microsoft Store 版は含みません。

## English

- Chat can connect before any allowed user is registered, and the first request can be approved on this PC. The guide now states how Mattermost personal DMs are scoped.
- History is easier to read. The target user column in the operations table stays readable in narrow windows, and the saved conversation list starts from the top after sorting or filtering. User names are shared between permission settings and history.
- Flyouts use an acrylic background that blends with the Mica window, and page titles take less vertical space. Page margins and scrolling are more consistent.
- Fixed the portable build's notification icon appearing orange in dark mode, and clarified messages when a portable update fails.

This preview provides portable ZIPs for x64 and ARM64 on GitHub Releases. The Microsoft Store version is not included.
