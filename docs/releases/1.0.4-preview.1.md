# Chat Agent Bridge 1.0.4-preview.1

## 日本語

このプレビューでは、GitHub Releases の x64 / ARM64 ポータブル版を配布します。Microsoft Store 版は含みません。

### 主な変更

- チャット接続ボタンを保存済みの必須設定から判定します。設定が足りないサービスは接続できず、「チャット」画面から「チャット設定」へ移動できます。
- 「依頼の実行中」または「チャット受信中」にPCのスリープを抑止する設定を追加しました。既定では無効で、AC 電源時だけに限定できます。画面オフやロックの設定は変更しません。
- 初回設定で必須項目と利用規約・プライバシーポリシーへの同意を見つけやすくしました。承認に関する危険度表示は補助情報として示し、承認権限や既定の安全設定は変えません。
- 概要の状態タイル、設定画面の文言と配置、サービスアイコン、テーマ切り替えを改善しました。
- 紹介サイトに英語表示、言語・テーマ切り替え、グループ化したナビゲーションを追加しました。
- 更新後の正常起動を確認したら、認証済み更新ファイルの一時ステージを整理します。ログと復旧用データは保持します。

### Preview に関する注意

- これは Preview 版です。GitHub Release からポータブル版を取得できます。Microsoft Store への提出・公開は行いません。
- v1.0.3 から最初に更新すると、旧版アップデータが一部のキャッシュ metadata を残すことがあります。「情報 → 詳細設定 → 保守」の更新用一時ファイルの整理で削除できます。新しいアップデータによる次回以降の更新では、正常起動後に認証済みステージを自動整理します。ログと復旧用記録は保持します。
- 実サービスへの接続・投稿は今回の検証では行っていません。チャット接続情報と許可ユーザーを確認してから接続してください。
- Muse Code、Kimi Code CLI、Qwen Code の実サービス認証・応答は引き続き未検証です。

## English

This preview is distributed as x64 and ARM64 portable builds through GitHub Releases. It does not include a Microsoft Store package.

### Highlights

- Chat connect buttons now reflect the required settings saved for each service. Incomplete services cannot be connected; Chat provides a shortcut to Chat settings.
- Add an opt-in setting to prevent the PC from sleeping while Bridge handles selected activity. It is off by default and can be limited to AC power. Screen timeout and lock settings are unchanged.
- Make required fields and Terms of Use / Privacy Policy consent clearer during first-run setup. Approval risk labels are advisory and do not change approval permissions or safety defaults.
- Refine General status tiles, settings wording and layout, service icons, and theme controls.
- Add English, language and theme controls, and grouped navigation to the introduction site.
- Clean the authenticated temporary update stage after the updated app starts successfully, while retaining logs and recovery data.

### Preview notes

- This is a Preview release distributed as portable builds from GitHub Releases. No Microsoft Store submission or publication is included.
- The first update from v1.0.3 may leave cache metadata because it uses the older updater. Remove it from Information → Advanced settings → Maintenance → Temporary update files. Updates handled by the new updater clean the authenticated stage after successful startup; logs and recovery records are retained.
- No real chat service connection or message send was performed during this release validation. Review saved connection details and allowed users before connecting.
- Authenticated service use with Muse Code, Kimi Code CLI, and Qwen Code remains unverified.
