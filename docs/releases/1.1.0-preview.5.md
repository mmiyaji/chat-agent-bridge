# Chat Agent Bridge 1.1.0-preview.5

## 日本語

- Slack・Mattermost・Discordの接続設定と初回設定ウィザードで、Botから参照できるチャンネルを名前で検索して選べるようになりました。Mattermostは送信先チャンネル、Slack・Discordは許可チャンネルを選択します。Discordは設定した許可サーバー内のチャンネルが対象です。
- 初回設定ウィザードからスレッドIDの細かな制限入力を外し、初回設定ではチャンネルと許可ユーザーを選ぶ流れに整理しました。既存の詳細設定は引き続き利用できます。
- 許可ユーザー一覧にチャットサービスから取得した表示名を併記します。名前を取得できない場合はユーザーIDを表示します。
- 折りたたみ見出しの上下余白とチャット接続状況セクションの間隔を調整しました。

Microsoft Store 版は含みません。プレビュー版は通常版と分けて試してください。x64 / ARM64 のポータブル ZIP を配布します。ARM64 は CI のクロスビルドと配布形式検査を行いますが、ARM64 実機での起動試験は行いません。

## English

- Chat settings and the first-run wizard can now search for channels visible to the bot and select them by name. Mattermost uses the selection as the destination channel; Slack and Discord use it as an allowed-channel list. Discord results are limited to configured allowed servers.
- The first-run wizard no longer asks for detailed thread ID restrictions. Initial setup focuses on choosing channels and allowed users; the detailed settings remain available afterward.
- The allowed-user list now shows display names retrieved from the chat service alongside user IDs. IDs remain visible when a name cannot be resolved.
- Spacing has been adjusted in collapsible headers and the chat connection status section.

This release does not include a Microsoft Store package. Test Preview builds separately from your regular installation. Portable ZIPs are provided for x64 and ARM64. ARM64 receives a CI cross-build and archive validation, but is not launched on ARM64 hardware.
