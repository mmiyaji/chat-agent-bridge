# Chat Agent Bridge 1.1.3

## 日本語

- チャットの依頼詳細を整理し、結果共有と添付ファイルの操作を分けました。狭いウィンドウや大きな文字サイズでも、会話一覧と詳細を行き来しながら操作できます。
- 起動時は保存済みの会話を復元してからセットアップ案内を表示します。承認待ちの依頼には保存後の設定を反映し、会話の作業フォルダーが使えない場合は承認設定を確認できないと表示します。作業フォルダー復旧後に再接続すると警告が消えます。
- 定期実行は作成元の Mattermost サーバーに紐づけます。夏時間への切り替えで指定時刻が存在しない日は、切り替え後の最初の有効時刻が実行対象になります。
- 新しいポータブル更新ヘルパーは画面の初期化完了まで待機し、初期化に失敗すると以前の版に戻します。1.1.2 からの更新は、ウィンドウ表示を確認する旧ヘルパーと互換性があります。

x64・ARM64 のポータブル ZIP を配布します。会話復元と承認の検証には模擬チャットを使用しました。今回の変更は実チャットサービスおよび ARM64 実機では未検証です。

## English

- Chat request details are easier to scan, with separate actions for sharing results and attachments. You can switch between the conversation list and request details in narrow windows and at larger text sizes.
- The inbox restores saved conversations before showing setup notices. Pending requests reflect saved approval settings. When a conversation's working folder is unavailable, the approval help says so. The working-folder warning clears after the folder returns and you reconnect.
- Recurring Mattermost requests stay with the server where they were created. When a daylight-saving transition skips the scheduled time, the request becomes due at the first valid local time after the transition.
- The new portable update helper waits for the main screen to finish initializing and restores the previous version if initialization fails. Updates from 1.1.2 remain compatible with the older helper, which checks that the window opens.

Portable ZIPs are available for x64 and ARM64. Conversation restoration and approval were tested with a mock chat service. Live chat services and ARM64 hardware were outside this release's verification.
