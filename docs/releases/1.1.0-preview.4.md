# Chat Agent Bridge 1.1.0-preview.4

## 日本語

- チャット設定の初期画面に、Slack・Mattermost・Discord の接続状況と各サービス設定への移動ボタンを追加しました。
- 共通設定を先頭に置き、サービス別設定との間に区切り線を追加しました。
- 許可ユーザーの管理場所を共通一覧に集約しました。サービス別設定には登録人数と一覧へのリンクを表示します。
- Mattermost の接続設定で、必須項目を任意項目より先にまとめました。
- ホームページ、README、ストア説明で、PC上で動くCLIエージェントと、そのCLIが利用する外部AIサービスを区別し、公式リモート操作は提供元のデスクトップアプリ等から利用できる場合があると説明しました。

Microsoft Store 版は含みません。プレビュー版は通常版と分けて試してください。x64 / ARM64 のポータブル ZIP を配布します。ARM64 は CI のクロスビルドと配布形式検査を行いますが、ARM64 実機での起動試験は行いません。

## English

- The initial Chat settings page now shows connection status for Slack, Mattermost and Discord, with a button to open each service's settings.
- Common settings now appear first, separated from service-specific settings by a divider.
- Allowed users are managed in one shared list. Each service's settings show its user count and link to that list.
- Mattermost's required connection fields are grouped before optional settings.
- The website, README and store description now distinguish the local CLI agent from the external AI service it uses, and clarify that official remote control may be provided through the provider's desktop app or another official client.

This release does not include a Microsoft Store package. Test Preview builds separately from your regular installation. Portable ZIPs are provided for x64 and ARM64. ARM64 receives a CI cross-build and archive validation, but is not launched on ARM64 hardware.
