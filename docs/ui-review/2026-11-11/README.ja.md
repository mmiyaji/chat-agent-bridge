# CAB UI検査と改善モック

検査対象のローカルmainは `849220d`。性能改善ブランチをmainへfast-forwardした後、`docs/ui-unslop-review` を作成した。

[現状と改善モックの比較ページ](comparison.html)

## 検査方法と範囲

Damir Sokolovskyの[unslop](https://github.com/heydamir/unslop)（`97daa3e`、CC BY 4.0）のチェック項目を、WinUIの画面設計と照合した。Fluentの配色、標準コントロール、既存の操作導線を前提とする。対象は保存済み会話一覧、アクセス許可一覧、会話詳細。

再確認ではWinApp CLIを使ってアプリを起動し、日本語・ダークテーマ・1,160×800 DIPのウィンドウで操作した。ビルドは849220dと同じ性能改善を含むローカル検証用x64 Releaseビルド。会話42件、実行500件、アクセス記録3件を専用の合成データとして用意した。

全般、手動実行、チャット、会話、実行記録、アクセス許可、利用状況、エージェント設定、チャット設定、情報の表示を確認し、画像をliveフォルダーへ保存した。接続やCLI実行、狭い幅、ライト・高コントラスト、読み上げは今回未確認。一般設定や実データの状態は合成プロファイルと異なる。

3組の比較は今回撮影した日本語画面と、それを参照して作り直したImageGenの改善モック。両側ともフィルターを閉じた同じ状態で比較する。生成画像の文字やアイコンは実装時にWinUIのリソースと置き換える。モック1では一覧の作業フォルダー・CLI・モデルを詳細へ移し、サービスと状態を残した。モック3では承認と結果共有を折りたたみとして明示した。

## 主な改善ポイント

### 1. 会話一覧の反復するメタ情報を短くする

現状は会話名、ユーザーとチャネル、作業フォルダーとCLIとモデル、サービスと状態と実行回数が並ぶ。長い状態行は折り返され、行の高さが変わる。複数会話を見比べる際に視線の移動が増える。

改善モックは会話名と時刻、ユーザーとチャネル、サービスと状態の3行を基本とし、状態を末尾へ寄せた。サービスや長い作業情報の省略分は詳細で確認する想定。実装時には、実行回数を残す場所と長い会話名の省略・ツールチップを合わせて確認する。

参照箇所は `desktop/ChatAgentBridge.Desktop/History/HistoryPage.xaml` の `SessionList.ItemTemplate`。

### 2. アクセス許可一覧で対象ユーザーを表示する

現状の固定列では時刻と操作名が省略される一方、右端の会話列が大きく空く。会話に属さない許可ユーザー追加のイベントは「ID —」と表示され、誰への操作かを一覧で確認できない。

改善モックはアクセス許可モードで時刻・操作・サービス・対象ユーザーを表示する。操作名に幅を割き、既存の詳細ペインで追加の識別情報を確認する。モック内の「Show details」は詳細を開く既存操作を明示した提案。

参照箇所は `HistoryPage.xaml` の `AuditHistoryList` と `HistoryPageViewModel.Audit.cs`。実装時は操作したユーザーと許可対象ユーザーを混同しないよう、イベントの保存項目を使い分ける。

### 3. 会話詳細の枠を減らして情報の階層を示す

現状は外側の詳細ペインと内側の複数カードが重なり、同じ情報にたどり着くまでに複数の見出し・余白を通る。今回のフィルターを閉じた状態でも、カードの重なりと長い作業フォルダーの表示で実行設定が画面下へ押し出される。

改善モックは一つの詳細面に会話の識別情報、最近の実行、作業フォルダーとエージェントをまとめ、区切り線で分けた。長いIDや引数は折りたたみへ集約し、よく使う切り替え操作は下部に置く。

参照箇所は `HistoryPage.xaml` の `SessionDetailPane`、`SessionConversationSummaryCard`、`SessionRuntimeCard`。

## 検証

- 比較HTMLとMarkdownのローカル参照先、PNG形式、縦横比を確認した。
- プロダクトのソース変更は含まない。今回の操作はページ遷移・会話選択・履歴モード切り替えまで。読み上げとモック実装後の表示は未確認。
