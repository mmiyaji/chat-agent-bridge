# 情報タブの実装・検証（2026-10-18）

Cliptonの実際の情報画面で、製品・バージョン・パッケージ・作者、Store更新、変更履歴、規約・プライバシー、終了操作という項目構成を確認し、Chat Agent Bridge向けに実装しました。

## 実装

- 左メニュー下部に「情報 / About」を追加しました。別画面から戻ると情報ページのスクロール位置を先頭へ戻します。
- 製品名、Package.Currentから取得した4桁のバージョンとパッケージ名、提供者mmiyaji、ウェブサイト・連絡先・ソースコードへのリンクを表示します。
- 開発プレビューではStoreページと更新確認を無効にし、その理由を表示します。Store署名の配布版ではパッケージファミリー名に対応するStoreページを開き、ボタン操作時だけ更新の有無を問い合わせます。[MicrosoftのStore更新API](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/package-updates-from-store)を使い、自動取得・インストール・定期確認は行いません。
- 更新内容をローカルのダイアログで表示します。規約・プライバシーは既存のPolicyDialogを再利用し、文書の閲覧だけでは同意を記録しません。
- Slack／MattermostとCLIとの通信、CLIから外部AIサービスへの送信の可能性を説明します。
- 終了操作では、実行中の作業のキャンセルとチャット切断を知らせ、キャンセルを既定にした確認を出します。
- 日英リソースと標準のテーマ対応ブラシを使用し、ダイアログにも現在のテーマを適用します。
