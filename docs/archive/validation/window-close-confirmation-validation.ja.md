# ウィンドウを閉じる際の確認（2026-10-20）

> 過去の検証・実装記録です。記載は当時の状態を示します。現行の手順は[ドキュメント索引](../../README.md)を参照してください。

## 動作

トレイ常駐がオフのときにウィンドウの×（Alt+F4を含む）を操作すると、終了確認を表示します。

- **終了する**：既存の完全終了処理で、チャット切断・CLI中断・履歴保存を行います。
- **トレイに格納**：接続と処理を維持したまま今回だけ画面を隠します。保存済みの常駐設定は変更しません。
- **キャンセル**：画面を開いたまま稼働を続けます。既定の操作はこちらです。

常駐がオンでトレイを利用できる場合は、従来どおり×で直ちに格納します。明示的な「完全終了」やトレイメニューの終了には、この確認を追加しません。Windowsのセッション終了処理も維持します。

トレイアイコンが利用できない場合は格納ボタンを無効化し、理由を表示します。確認中に利用可否が変わった場合も説明とボタン状態を更新し、選択後にも利用可否を確認します。他のダイアログを表示中に×を操作した場合は、そのダイアログを維持します。
