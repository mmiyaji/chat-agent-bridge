バージョン確認の異常終了では終了コードを案内します。.NETホストの既知の実行環境不足メッセージは専用の案内に置き換えます。任意の標準エラーや内部例外をそのまま表示しません。

## 未信頼フォルダーからの追加導線

作業先自体、または上位フォルダーがジャンクションなどのリンクの場合は、実フォルダーの候補も診断します。リンクと実フォルダーの両方を示し、利用者が選んだ場合だけ作業先を実フォルダーへ変更して、その範囲を信頼対象に追加します。既存の ExecutionPolicy のリンク拒否や範囲制限は変更していません。

初期設定ガイドでは、未信頼の作業先を保存できずCLI確認へ進めない場合も、作業フォルダーのページから同じ確認画面を開けます。このページでは追加後に［保存して次へ］で進み、次ページでCLIをチェックします。
