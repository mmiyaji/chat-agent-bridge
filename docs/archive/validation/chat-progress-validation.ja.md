# チャットの受付・進捗投稿（2026-10-19）

> 過去の検証・実装記録です。記載は当時の状態を示します。現行の手順は[ドキュメント索引](../../README.md)を参照してください。

未公開のローカルビルド `0.1.0-preview.5`（アプリ `0.1.0.4`）で、SlackとMattermostの依頼ごとに受付投稿を作成する。同じ投稿を実行開始時と約30秒ごとに編集し、完了・失敗・停止・拒否・切断時に終了状態へ書き換える。

## 表示と共有範囲

- 進捗には状態と実行開始からの経過時間だけを載せる。プロンプト、CLIの内部出力、承認の詳細は含めない。進捗説明用のAI呼び出しは行わない。
- 結果の自動共有が有効なら、完了への編集後に結果本文を別投稿する。手動共有ではPCの「結果を共有」から投稿し、共有しない設定では本文を送らない。失敗したCLIの出力も自動共有しない。
- 受付と更新は元の会話へ送る。各送信前に最新の許可設定を確認する。編集対象は、この接続で作成した専用の投稿IDに限り、別ユーザー・別スレッド・別接続のハンドルを受け付けない。
- 送信・編集エラーはAI実行から切り離し、PCの接続・通知欄に案内する。編集に失敗しても代わりの進捗投稿を増やさない。
- 切断時は未終了の投稿を終了状態へ更新する。権限を外した会話への更新や、アプリの強制終了・通信断での最終更新は保証されない。
