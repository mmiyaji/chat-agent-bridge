# チャット画面のGallery UI導入

> 過去の検証・実装記録です。記載は当時の状態を示します。現行の手順は[ドキュメント索引](../../README.md)を参照してください。

対象はWinUI 3版のチャット画面です。「会話を見ながら操作」のサンプルを基に、一覧と詳細を並べる構成を維持します。狭いウィンドウでは一覧と詳細を切り替え、戻る操作で一覧へ戻ります。

## 変更範囲

- 検索候補は読み込み済みの会話情報から生成します。候補の取得で外部サービスへ問い合わせません。候補を選ぶ操作でAI実行や承認は行いません。
- 依頼者はPersonPictureで表示します。Slack・Mattermost・DiscordのユーザーIDに対応するプロフィール画像を取得し、取得できない場合は保存済みの名前の頭文字、名前もない場合は汎用アイコンを使います。IDから頭文字を作りません。
- 操作バーは既存の承認・拒否・停止・結果共有・ファイル共有コマンドを呼び出します。権限確認、確認ダイアログ、ファイル共有の同意と制限を維持します。
- 補足説明は利用者が開いたときだけ表示します。承認や実行の状態、エラーは補足説明に隠しません。

## 検証

実画面の確認には通常利用の設定と分離したデータフォルダー、ローカルのチャットサーバー、検証用CLIを使います。実サービスへの投稿や有料AIの呼び出しは行いません。

会話の保存、実行ポリシー、添付ポリシーを対象にした既存のCoreテストは14件成功しています。

2026-10-24に、英語／日本語とライト／ダークの4通りで各13項目、計52項目の画面テストが成功しました。通常幅1160×800と狭い幅500×600で、検索候補、同名候補の選択、承認のキャンセル、実行の停止、拒否、結果・添付の確認とキャンセル、一覧へ戻る操作、補足説明の開閉を確認しました。候補の選択だけではAIを実行せず、共有のキャンセルでは投稿・ファイル送信を行わないことも確認しています。

通信層はプロフィール画像のテスト11件を含む264件が成功しました。日英リソースのキー・書式引数・参照と、SettingsExpanderの検証も成功しています。

画面確認で見つかった次の問題を修正しました。

- 実行中の「停止」ボタンへ表示が切り替わらないケース。
- 会話を切り替えた際に、詳細欄へ前の依頼者の画像が残るケース。画像がない会話では画像レイヤーを非表示にし、別の依頼者の画像が見えないことも画面テストで確認しました。
- 狭い画面で無効な接続ボタンが会話領域を圧迫する点。接続済みの場合は切断操作だけを残します。
- 補足説明を閉じる操作のわかりにくさ。「閉じる」ボタンを追加しました。日本語の説明文にあった重複表現も短くしました。

再実行する場合は、ポータブルの分離ビルドと自己完結型TestAgentを指定して `desktop/InboxGalleryUiSmoke.ps1` を実行します。検証結果のJSONと各画面のPNGは、実行ごとに `desktop/artifacts/<GUID>/` へ保存されます。実行例:

```powershell
pwsh -NoProfile -File desktop/InboxGalleryUiSmoke.ps1 `
  -AppDirectory D:/git/chat-agent-bridge/desktop/artifacts/inbox-gallery-app `
  -TestAgentPath D:/git/chat-agent-bridge/desktop/artifacts/inbox-gallery-testagent/ChatAgentBridge.TestAgent.exe
```

## プロフィール画像の扱い

表示された行と選択中の会話だけが画像を要求します。同時取得は2件までで、取得済みの画像は24時間、取得失敗は5分間キャッシュします。画像は設定フォルダー内の `avatar-cache` に保存し、最大100枚・50MBに制限します。キャッシュファイル名にトークンやユーザー名は含めません。

Mattermostでは設定済みサーバーと会話の接続元が一致する場合だけ取得します。SlackとDiscordではユーザーIDを照合し、画像の取得先を限定します。画像配信先にBotトークンを送らず、リダイレクトにも追従しません。受信サイズは512KiB、PNG/JPEGの寸法は2048×2048以下に制限します。

通信層のテストでは3サービスの取得経路、認証情報の送信先、接続元・ユーザーの不一致、取得先URL、リダイレクト、サイズ、タイムアウト、キャンセル、キャッシュ期限と再生成後の再利用を確認します。外部サービス上の実アカウント画像は今回の隔離テストには含めません。
