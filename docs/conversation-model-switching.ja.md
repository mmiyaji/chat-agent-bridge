# 会話のモデルを切り替える

CodexとClaude Codeで、同じAI会話の履歴を引き継いでモデルを切り替えられます。

## PCから

「履歴と会話」で会話を選び、「モデルを切り替える」を開きます。「CLIからモデル候補を取得」で取得した候補からモデルと対応する推論の強さを選んで保存します。次の依頼から適用されます。

モデル欄を空にすると「エージェント設定」のモデルに戻ります。新しい会話の初期モデルも「エージェント設定」で指定します。

## Slack・Mattermostから

AIとの会話があるスレッドに、会話を開始した本人が返信します。

| コマンド | 操作 |
| --- | --- |
| `!cab model` | この会話の現在のモデルと推論指定を確認 |
| `!cab model list` | 設定されたCLIからモデル候補を取得 |
| `!cab model モデルID` | 候補の正確なIDを指定して切り替え |
| `!cab model default` | エージェント設定に戻す |
| `!cab command` | モデル操作を含むコマンド一覧 |

設定はサービス・接続先・チャンネル・スレッド・ユーザー単位で保存され、他ユーザーの会話やアプリ全体の既定モデルには影響しません。まだAI会話がないスレッドでは変更できません。

実行中や同じ会話に承認待ちの依頼がある間は変更できません。モデル変更時は以前の推論指定を解除し、変更先モデルのCLI既定値（エージェント設定と同じモデルの場合はその推論指定）を使います。推論の強さを明示する場合はPCの会話設定から選びます。「初回のみ承認」はモデル・推論指定の変更後、次の依頼で再承認が必要です。

候補取得はモデルへの依頼を実行しません。成功したCLI候補をプロバイダー・実行ファイル・作業フォルダーごとに5分間キャッシュし、繰り返しのCLI起動を抑えます。変更前後に許可設定を再確認し、候補取得中に会話が更新された場合は上書きせず再試行を案内します。

## 検証

`ConversationModelServiceTests` は永続化、ユーザー・スレッド・接続先の分離、CLI候補の照合、キャッシュ期限、取得中の許可取り消しと同時更新を検証します。

`RemoteOperationsUiE2E.ps1 -ModelsOnly` は隔離したMattermostプロトコルサーバーとオフラインClaude CLIを使い、初回承認、候補取得、チャットでの変更、再承認、同一セッションの継続、権限分離、PCの候補選択、既定への復帰、コマンドによる余分なAI実行がないことを確認します。日本語・ダークと英語・ライトで実施します。実サービスへの投稿や有料モデルへの依頼は行いません。

```powershell
pwsh -File desktop/RemoteOperationsUiE2E.ps1 -AppDirectory desktop/artifacts/model-switch-ui-publish -TestAgentDirectory desktop/artifacts/model-switch-testagent -Language ja -ModelsOnly
```
